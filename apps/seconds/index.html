Privacy

Exact Seconds does not require an account, show ads, or use advertising tracking. It uses limited PostHog product analytics only to measure whether configured widgets continue to be serviced by iOS over time.

The Widget Extension may send a widget_active event no more than once every seven days. The event includes a random persistent installation identifier, event timestamp, widget family, and the Widget Extension as the source. Exact Seconds does not send app-open events, widget colors, visual design choices, precise location, IDFA, or data for cross-app advertising.
